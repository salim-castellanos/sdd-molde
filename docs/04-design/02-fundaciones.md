# Fundaciones (tokens)

No hay librería de tokens. Hay valores para no improvisar marca.

| Token | Clave v0 | [RELLENAR fork] |
| --- | --- | --- |
| Color fondo | claro (`#f8fafc` o equivalente Tailwind `slate-50`) | |
| Color texto | oscuro (`slate-900`) | |
| Color error | rojo oscuro, no solo color: también texto | |
| Color primario / botón | un azul sobrio (`blue-700`) | |
| Tipo | sistema / sans del navegador | font de marca |
| Escala tipo | heading ~1.5rem, body 1rem, help 0.875rem | |
| Espacio | stack 1rem; page padding 1.5rem | |
| Ancho auth | máx. ~28rem, centrado | |
| Radio | 0.375rem | |
| Elevación | ninguna (sin sombras) | |

Tema oscuro: fuera de alcance.

Si cambia un token, se cambia **aquí** y el plan de la spec de UI lo cita. No en un chat.
