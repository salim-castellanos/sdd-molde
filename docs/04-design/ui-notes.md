# Notas de UI

No hay design system. Hay restricciones para que el agente no improvise una marca.

- Fondo claro, una columna, ancho máximo ~28rem en auth.
- Un heading, un formulario, un párrafo de ayuda.
- Errores de campo bajo el input. Error de servidor arriba del formulario.
- Contraste suficiente (texto oscuro sobre fondo claro). No animaciones.
- Password: input type password; no mostrar fortaleza fancy, solo la regla de la spec.
- No ilustraciones, no OAuth buttons, no “continuar con Google”.

Si más adelante hay marca, se escribe aquí y se referencia desde el plan, no al revés.
