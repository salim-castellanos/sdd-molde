# Kit HTML (plantilla)

Preview **estático** del sistema de diseño. Se itera aquí (HTML/CSS). El producto (`apps/web`) se implementa **después**, en el stack de la spec, copiando tokens y markup — no al revés.

```text
docs/04-design/          contrato (markdown)
docs/04-design/kit/      este preview (HTML)
refs/                    plantilla MIT de terceros (clone, gitignore; opcional)
apps/web/                implementación (cuando el kit está listo)
```

Abrir `index.html` en el navegador. No es la app. No es Storybook. No es el clone de GitHub.

Si el producto tiene **puerta pública**: un HTML por pantalla que se itera (`landing.html`, `auth.html`). Auth no se diseña como columna huérfana si `/` ya tiene atmósfera. Oficio (capítulo = trabajo, preview = producto, foto ≠ ilustración, contraste al mover paneles): `01-principios.md`.
