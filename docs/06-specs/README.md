# 06 — Specs

Artefactos **compuestos**, no el punto de partida.

Una spec nace en un paso `compose` del runbook: HU + diseño + arquitectura + gates + steerings aplicables. Recién el paso `implement` la ejecuta.

Hoy este folder está vacío a propósito. El runbook [001-identidad](../07-runbooks/001-identidad/runbook.md) va en el paso 2: componer `001-roles-permisos`.

No crees una spec porque “hay que implementar login”. Crea o sigue el runbook.
