# Steering — orquesta

## Qué es

Una persona, varios roles. El agente del chat es el orquestador: abre el rol del paso y junta lo que cada uno dejó en la mesa.

## Cuándo cargarlo

“¿Quién hace este paso?”, “llama al que compone”, “qué descubrió el anterior”, varios roles en un corte, orquestar.

## Cuándo no

Un typo. Una pregunta de producto que no cambia de fase. No abras todos los roles “por si acaso”.
