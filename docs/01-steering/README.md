# 01 — Steering

Los steerings son **routers**, no enciclopedias. Leer una card no debe traer todo el producto a contexto.

1. Empieza por el padre: [catalog.md](catalog.md).
2. Abre solo las cards cuyo trigger coincide.
3. La card dice si cargar más y **qué** archivo.

Al agregar una card: fila en el catálogo + archivo delgado (cuándo / cuándo no / a qué apunta). El Explorer no debe ganar un markdown largo disfrazado de steering.

El detalle vive en [context/](context/) o en `docs/03-architecture`, `docs/04-design`, etc.
