# Steering — structure

## Cuándo cargarlo

“¿Esto va en api o en web?”, nombres de carpetas, extraer submodule, crear un módulo. Si el tema es “que el IDE lo entienda”, usa la card `ide`.

## Cuándo no

Escribir aceptación de una HU. Elegir copy de un botón.

## Si aplica, cargar

- Si el trabajo es una instancia y existe `ecosystem/<instancia>/docs/01-steering/context/structure.md`, carga **ese** archivo.
- Si el trabajo es la instancia y ese archivo no existe, no apliques el árbol de Clave.
- Si el trabajo es el molde o un fork de la raíz: [context/structure.md](context/structure.md).
