# Steering — tech

## Cuándo cargarlo

Nueva dependencia, cambio de stack, “¿Postgres o SQLite?”, validación compartida, tests.

## Cuándo no

Redactar una HU. Dibujar una pantalla. El stack no entra en la historia.

## Si aplica, cargar

- Si el trabajo es la instancia y existe `example/docs/01-steering/context/tech.md`, carga **ese** archivo.
- Si el trabajo es la instancia y ese archivo no existe, el stack no está elegido. No apliques [context/tech.md](context/tech.md): es el arquetipo Clave.
- Si el trabajo es el molde o un fork de la raíz: [context/tech.md](context/tech.md).
